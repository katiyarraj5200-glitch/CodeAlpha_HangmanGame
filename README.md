# 🎮 Hangman Game

A simple word-guessing game built using Python.

## Features
- Random word selection
- Maximum 6 incorrect attempts
- Input validation
- Tracks guessed letters
- Win and lose messages

## Technologies Used
- Python 3
- Random Module

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run:

python hangman.py
